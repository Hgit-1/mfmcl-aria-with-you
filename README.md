# Aria with You

季节主题插件 for [MFMCL](https://github.com/Hgit-1/MFMCL)。按真实日期切换 Aria 的春／夏／秋／冬形象：配色、穿搭、动作与天气都随之改变。

**当前状态：素材与清单已就绪，可打包为 `.mflp`。但装进 0.1.0 版启动器后不会改变画面** —— 原因见下方「安装后的实际效果」，这是本仓库最需要你知道的一件事。

---

## 安装后的实际效果

`.mflp` 包会被启动器接受，插件页会列出它、显示它申请的权限、开关也能拨动。**但立绘不会出现**，原因是启动器的插件系统当前只执行**声明式贡献**：

| 能力 | 0.1.0 启动器 | 本仓库 |
| --- | --- | --- |
| 解释清单、展示权限、记住启用状态 | ✅ | 提供 |
| 执行 `jvmArgs` / `env` / `preLaunch` / `backupBefore` | ✅ | 不涉及 |
| 用插件自带的图片渲染界面 | ❌ 未实现 | 提供 36 张 |

渲染逻辑——判断季节、算对比度安全的强调色、把立绘摆在主页与各页右下角——目前写在启动器源码里（`design/flowlaunch-ui/utils/aria.ts` 与 `components/AriaFigure.tsx`），不在插件里。`normalizePlugin` 会丢弃清单里任何它不认识的字段，所以清单写素材路径也不会被读取。

这不是打包没做好，是插件系统的边界。**要真正看到立绘，需要启动器支持「插件声明素材、界面按声明渲染」**，那是一次双重改动：启动器增加素材渲染通道，本插件把 `artwork` 块接上去。

## 现在能用它做什么

1. **作为素材源**：36 张透明背景立绘（四季 × 全身/半身 + 5 页 × 四季），全部按同一角色设定生成，可直接用于其他启动器或同人项目。
2. **作为插件包样例**：`.mflp` 的结构、清单字段、索引格式都是照 0.1.0 启动器的解析器写的，可作为写其他插件的参考。
3. **给未来的渲染通道做准备**：`manifest.json` 的 `artwork` 块已经写好四季与分页的路径模板，启动器一旦支持，改一处就能接上。

## 打包

```sh
python tools/package.py            # 生成 dist/aria-with-you-<version>.mflp 与 index.json
python tools/package.py --check    # 校验 index.json 里的 sha256 与重新打包的结果一致
```

打包是确定性的：条目按名字排序、时间戳固定为 1980-01-01、压缩级别固定。同一份源码两次打包得到相同的字节，否则每次发布都会看起来像「插件变了」，而索引里记下的哈希第二天就失效。

发布时把 `dist/*.mflp` 上传到 GitHub Release，`index.json` 里的 `download` 指向那个资产地址，启动器就能把本仓库加为插件源。

## 角色设定

发卡是辨识度最高的细节，因此有单独规格并会被自动校验。

- 颜色 `#bdd699`（浅黄绿），平涂、细描边
- 形状：顶部一块宽横方块（约 2.2:1），下方六段扭转立方体逐段收小，末端小菱形
- 位置：观察者左侧、耳前、上缘与太阳穴齐平
- **没有**流苏、丝带或花；它是唯一的头饰

人物配色取自角色设定图实测值：发色 `#dfcec1`、瞳色 `#c2894f`、裙 `#9ca5bf`、袜 `#f7f7f5`、鞋 `#6b4b3a`、外套 `#cfbda8`。

## 重新生成素材

`tools/gen.py` 调用图像生成接口重出全部素材，`tools/audit.py` 复核，`tools/seg.py` 抠像。三者都在本仓库里，用本仓库的 `assets/` 作为输出与输入。

```sh
export MFMCL_ARIA_IMAGE_KEY=...                                   # 图像接口的 key，不写进仓库
export MFMCL_ARIA_OUT_DIR="$PWD/assets"                           # 输出与复核的目标目录
python tools/gen.py                 # 四季 × 全身/半身
python tools/gen.py pages           # 五页动作 × 四季
python tools/audit.py               # 复核发色、发夹、边缘晕边，并生成浅/深背景对照表
```

`MFMCL_ARIA_OUT_DIR` 是必填的：脚本刻意不猜路径。它们原本住在启动器仓库里，按相对位置找同级目录；一旦两个仓库的摆放方式变了（克隆到别的盘、放进子目录），猜错的结果是往一个新建的空目录里写 36 张图，比直接报错更难发现。

`gen.py` 内置校验：发夹缺失、方向反了、或退化成单个方块时会自动重新生成。`audit.py` 要求的阈值都标了来源，没有凭空选取的数字。

改完素材后记得升 `manifest.json` 的 `version` 并重新打包——启动器按 tag 锁定素材（`utils/aria.ts` 的 `ART_PIN`），不升版本的话用户看到的还是旧图。
